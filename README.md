# ApexPlanet Data Analytics Internship – Task 1

## Data Immersion & Wrangling

This repository contains my work for **Task 1 of the ApexPlanet 60-Days Data Analytics Internship Program**.

The main objective of this task is to understand, assess, clean, transform, and prepare the provided dataset for further data analysis.

---

## 📌 Project Objective

The objective of Task 1 is to:

- Understand and explore the provided dataset
- Create a data dictionary
- Assess the quality of the data
- Identify missing values
- Identify duplicate records
- Check data types and inconsistent formatting
- Identify potential outliers
- Clean and transform the dataset
- Perform basic feature engineering
- Generate a final analysis-ready dataset
